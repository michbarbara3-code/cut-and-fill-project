# Cut and Fill Volume Calculator with Mass Haul Analysis
**Group 8 Coursework Project**

## Description
This program reads survey data from a CSV file, calculates earthwork volumes (Cut and Fill) using the End-Area Method, and computes the cumulative Mass Haul. It outputs a formatted terminal report and plots a visual Mass Haul Diagram.

## How to Run This Program
1. Ensure Python 3 is installed.
2. Install the graphing library: `pip install matplotlib`
3. Run `main.py`. The program will read `sample_stations.csv`, print the report, and display the graph.
