Cut and Fill Volume Calculator With Mass Haul Analysis

A Python-based tool designed to calculate earthwork volumes (Cut and Fill) between survey stations using the End-Area method. It also calculates the Cumulative Mass Haul Ordinate and visualizes the results with an interactive graph.
 
 Features
- Interactive Input:Enter chainage, cut area, and fill area for multiple stations dynamically.
- End-Area Calculation: Accurately calculates volumes between sections.
- Mass Haul Ordinate: Keeps a running total of the net volume to determine haul requirements.
- Interactive Graphing: Uses Plotly to generate a beautiful, hoverable Mass Haul Diagram.

Prerequisites
You need Python installed on your computer.
You also need the plotly library. 
To install Plotly, run:
                       Pip install plotly

How to Run
1. Clone this repository or download calculator.py.
2. Open your terminal and navigate to the project folder.
3. Run the script:
Python calculator.py
4. Follow the prompts in the terminal to enter your station data. Type done when finished to generate the graph.
